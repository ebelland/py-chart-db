Closed in the stylesheet/surface pass:
  - App style can be a .qss file chosen from disk (Settings -> App style ->
    "From file..."). The sheet is asked which palette to pair with it, so a
    dark sheet no longer gets the light palette under it.
  - Settings stayed unreachable from the macOS menu bar: it carried
    PreferencesRole, Cocoa moved it into the application menu, and the
    menu-bar rebuild left that native item pointing at a dead QAction. It is
    pinned into the File menu with NoRole now - the explicit role matters,
    since the default TextHeuristicRole relocates it by reading its text.
  - Fit accepts 3D functions: Z = f(X, Y) against a series' x/y/z roles.
  - Renderer options are converted to the type they declare, which is what
    stopped a typed-in rstride or linewidth from raising inside Matplotlib.
  - Six surface/contour demos: wave interference, membrane mode, Rosenbrock.

      Half-done already, and the missing half is discoverability: render_figure
      ._apply_aspect_options applies "aspect" and "adjustable" to every axis
      today, so {"aspect": "equal"} in the axis options gives an equal x/y step

      declared in any renderer's Kwargs, so nothing offers them in the options
      editor and you have to know the name to type it. Declaring "aspect" on
      the base (choices: auto / equal, plus a number) would put it in every
      chart's editor without touching a renderer.

P2-5  ChartPanel: downsample large series for display (LTTB) above ~50k points
      Preserves visual shape at a fraction of the draw cost.
      PROMOTED IN VALUE by the P1-2 measurements: with blitting in place the
      repaint is flat at ~2.55ms, so the hover hit test is now the dominant
      cost at scale - 4.63ms of a 7.21ms budget at 500k points. Downsampling
      shrinks the hit test and the draw together. This is the next
      interactivity item worth doing.
