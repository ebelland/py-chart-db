N-4   3D / contour renderer, gridded and scattered
      Two shapes of input, one renderer: values on a regular grid go straight
      to contour/contourf, and scattered x/y/z has to be interpolated onto one
      first (griddata, or a triangulation with tricontour - the triangulation
      is honest about where there is no data, the grid is not). Deciding which
      case is in front of you is the part worth getting right: a "grid" that
      is only nearly regular must not be treated as one.
      Pairs with the heatmap/imshow line under P2-1.

N-5   sqlite_repo: 3013 lines in one module
      Split by subject rather than by size - connection and pragmas, tables
      and import links, descriptors, saved queries, maintenance - and keep
      SqliteRepo as the one class the application talks to, so no call site
      changes. The dataclass with a mutable OrderedDict field and the series
      cache belong with the connection, not with the descriptors.

N-6   icons: finish the SFSymbol / Segoe Fluent migration
      This is P0-7 plus the rest of it: seven of the failing tests are the
      same cause. Actions naming SVGs that were deleted, win11/macOs icons
      with no common fallback, and icon files nothing asks for any more.

N-8   ChartPanel: "Add vertical line" / "Add horizontal line"
      Same context menu, with a small dialog for the line style, persisted in
      the axis options like the annotations are - so they survive a reload and
      can be edited from the properties panel afterwards. A new options key
      ("lines") drawn by the base renderer beside apply_annotations.

N-9   documentation
      docs/DEVELOPMENT.md is behind the renames, the fit rework and the new
      startup path; and there is no user manual at all. The manual should be
      one HTML file, built from the same catalogue the UI reads so the two
      cannot drift.

N-3   attribute control charts (p, np, c, u)
      The half of SPC N-1 does not cover. These plot a proportion or a count
      rather than a measurement, so the limits are binomial/Poisson rather
      than normal, and the limits vary per point when the sample size does.
      Needs a "sample size" role alongside x and y, which is the real work.

      Preserves visual shape at a fraction of the draw cost.
